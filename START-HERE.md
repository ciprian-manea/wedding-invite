# Start here: building the invitation draft with Claude Code

This kit gives Claude Code everything it needs to know: what to build (`docs/`), how to work
(`CLAUDE.md`), repeatable workflows (`.claude/skills/`), two helper subagents (`.claude/agents/`),
automatic checks (`.claude/settings.json` hooks) and browser and docs tools (`.mcp.json`).

Two tracks run side by side: **code** (Claude Code, about 2 weeks part-time) and **art**
(you, with image/video tools, start on day 1). The code never waits for the art, because
placeholder media is generated by a script.

## Step 0 · Install (30 min, once)
1. Node.js LTS, Git, `jq` and `ffmpeg` (macOS: `brew install node git jq ffmpeg`;
   Windows: use WSL, then `sudo apt install jq ffmpeg`).
2. Claude Code: follow https://code.claude.com/docs/en/overview, then run `claude` once and log in.
3. A GitHub repo (private) and a Vercel account linked to GitHub.

## Step 1 · Create the project and add the kit (10 min)
```bash
npx create-next-app@latest wedding-invite
#   TypeScript: Yes · ESLint: Yes · Tailwind CSS: Yes · src/ directory: No · App Router: Yes · import alias: default
cd wedding-invite
```
Copy everything from this kit into `wedding-invite/`, including the hidden `.claude/`, `.mcp.json` and
`.gitignore` (replace the generated `.gitignore`; the kit's version includes the Next.js entries).
```bash
chmod +x scripts/*.sh .claude/hooks/*.sh
git add -A && git commit -m "Project + Claude Code kit"
```

## Step 2 · First Claude Code session: check the setup (10 min)
```bash
claude
```
- Approve the project MCP servers when asked (Playwright and Context7). Run `/mcp` to see both connected.
  If Context7 fails, check its README for the current URL and update `.mcp.json`.
- Run `/context`: CLAUDE.md, PROJECT.md, ARCHITECTURE.md and TASKS.md should be listed.
- Run `/plugin` and install the **frontend-design** plugin and a **TypeScript** code-intelligence plugin if offered.
- Type `/` and confirm `/milestone`, `/encode-media` and `/new-section` appear.

## Step 3 · M0 setup (1 session)
```text
/milestone 0
```
Claude shows a plan and waits. Read it, correct anything, approve. At the end you should see a screenshot of
the names on the paper background, and the placeholder video in `public/media/jardin-blanc/`.
Then `/clear`.

## Step 4 · M1 opening sequence (1–2 sessions, the most important)
```text
/milestone 1
```
When Claude says it's done:
1. `npm run dev -- -H 0.0.0.0`, find your computer's IP, open `http://<ip>:3000/demo?to=Dragă%20Vasile` on your iPhone and Android.
2. Also send the link to yourself on WhatsApp and open it there.
3. Tell Claude exactly what you saw ("on iPhone there's a white flash after the video", "music didn't start with silent mode on").
   Paste phone screenshots straight into the prompt.
Commit, then `/clear`.

## Step 5 · Art track (in parallel, from day 1)
You make the images, video clips and music in external tools; Claude Code guides and checks every step
and assembles the final video. The full brief with ready prompts is `docs/ART_BRIEF.md`.
Run these in a separate Claude Code session from the coding work:
1. `/art next`: tells you the next step with the exact prompt to paste.
2. Generate frame A (closed envelope) in your image tool. Save it to `assets-src/jardin-blanc/frames/A-closed.png`.
3. `/art monogram A&I`: Claude draws the seal monogram as SVG; place it on the seal in Photopea or Photoshop.
4. Make frame B (flap open) from A, and frame C (the orangery scene). Then `/art review`: Claude looks at the frames
   and tells you what doesn't match.
5. In a video tool with start + end frame mode, make 6–10 takes of clip 1 (A → B) and clip 2 (B → C).
   Save them in `assets-src/jardin-blanc/takes/`, then `/art review`: Claude makes contact sheets and picks the best takes.
6. `/art assemble clip1-04.mp4 clip2-07.mp4` (your chosen takes): Claude joins them, adds the still holds and
   checks the length. No video editor needed.
7. License music (`/art music` gives the brief and checklist) and save it as `assets-src/jardin-blanc/music.wav`.
Tick progress in the "Art track" section of `docs/TASKS.md`.

## Step 6 · M2 and M3 sections (2–4 sessions)
```text
/milestone 2
```
`/clear`, then `/milestone 3`. Check the screenshots Claude shows after each section; ask for changes in plain words
("schedule line should be thinner and gold", "names too small on iPhone SE").

## Step 7 · M4 polish and preview deploy (1–2 sessions)
```text
/milestone 4
```
Import the repo in Vercel (it detects Next.js). Every push makes a preview URL. Run Lighthouse on it and
send it to 3–5 friends on WhatsApp.

## Step 8 · M5 real assets (1 session, when the art is ready)
```text
/milestone 5
```
It runs `/encode-media jardin-blanc`, swaps the placeholders, and tunes the name overlay to the real envelope.

## How to work well with Claude Code here
- **One milestone per session, `/clear` between them.** The docs carry the context, not the chat.
- **Plan first** for anything bigger than a small fix: press Shift+Tab for plan mode, or let `/milestone` stop at its plan.
- **Be specific and show evidence:** paste phone screenshots and say the device and browser.
- **Stop early:** press Esc as soon as it goes the wrong way; `Esc Esc` or `/rewind` undoes edits.
- **After two failed corrections,** `/clear` and give one better prompt that includes what you learned.
- **Ask for the subagents:** "use mobile-qa to test the envelope on iPhone", "use spec-reviewer on the diff".
- **Commit after each milestone** so you can always go back.
- **Keep docs true:** when you change your mind (a color, a section), ask Claude to update the doc first, then the code.
